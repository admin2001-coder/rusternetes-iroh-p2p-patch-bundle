# IROH P2P Networking (Experimental)

This document describes an experimental peer-to-peer overlay networking approach for Rusternetes using Iroh.

## Goals

- Provide lightweight P2P connectivity between controller and nodes
- Enable NAT traversal where possible
- Allow decentralized cluster communication

## Status

This is a patch bundle / prototype scaffold.
